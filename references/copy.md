# Copy for video

Decide what language adds to the image: context, consequence, comparison, emphasis or an invitation. Sometimes a repeated visual label is useful for accessibility or recognition; avoid a blanket ban on saying what is shown.

## Questions worth asking

- What should a viewer understand after one watch?
- Is the language specific to this subject, and supported where factual?
- Does it sound natural aloud if spoken?
- Can it be read at the intended size and speed while the image competes for attention?
- Does the ending ask for an action the film has made intelligible?

Early branding, feature lists, multiple proof points, spoken taglines and wordless films can all work. Select them for the brief. Writing the ending first can clarify purpose, but is not a prerequisite. Edit redundant words without imposing an arbitrary percentage cut.

## Reading-time prompts

The scripts flag planned text above 17 characters per second as an uncalibrated reading-effort prompt and above 25 as a closer-review trigger. These are not universal typography limits and do not measure the actual render. Audience, language, familiarity, type size, repeated words and visual complexity matter. Only an explicitly chosen `delivery.max_text_cps` becomes a blocking plan requirement; actual legibility still needs inspection.

A rough narration estimate of 2.5 words per second is a planning prompt. Time and listen to the real delivery before deciding it is understandable. A 42-character/two-line subtitle convention is not a restriction on posters, title cards or kinetic typography.

The checker can flag familiar phrases such as “Introducing”, “Meet”, “game-changer” or “seamless”. This is advice, not a blacklist. Retain a phrase when it is the best fit; revise it when it is empty or interchangeable.
